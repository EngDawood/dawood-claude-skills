# APA 7 (only when the user asks for APA)

Use these values in place of the plain style table.

| Element | Style |
|---|---|
| Page | US Letter, margins 2.54 cm, page number top right |
| Body | Times New Roman 12, double-spaced, left-aligned, first line indented 1.27 cm, no space between paragraphs |
| `#` | paper title, bold centered; Title style |
| `##` | APA Level 1, bold centered |
| `###` | Level 2, bold flush left |
| `####` | Level 3, bold italic flush left |
| `#####` | Level 4, bold indented |
| `Table n: Title` | "Table n" bold on its own line, title italic on the next |
| Table | horizontal rules only (top, under header, bottom), header row repeats, rows unsplit |
| `Note.` line after a table | "Note." italic, then the text |
| Lists | double-spaced, every numbered list restarts at 1 |
| `References` heading | starts a new page; entries hanging indent 1.27 cm |
| Pictures and charts | centered, scaled to the text width; caption under |
| Cover / contents page | none unless asked |
